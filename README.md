# 🎓 University Projects

> A complete archive of my academic and personal activities throughout my bachelor's degree in Computer Science.

This repository contains an organized collection of the projects, assignments, exercises, and personal projects I have worked on throughout my university studies.

Since I am still completing my bachelor's degree, this repository is an **ongoing archive** and will be updated as I progress through the remaining semesters.

---

## 📌 About This Repository

The projects in this repository are organized **by semester** and divided into two main categories:

* 🏫 **School** — Projects, assignments, exercises, and voluntary university work related to my courses.
* 🧑‍💻 **Personal** — Projects that I independently started and worked on as part of my own learning path and interests.

Not every course required a project. Therefore, the projects listed under each semester correspond only to the courses and subjects for which I completed a project, assignment, exercise, or related work.
